# Design System — Forest Ledger

The frontend uses a custom **Forest Ledger** theme (originally a Glassdoor-inspired refresh of the Editorial Broadsheet, since pushed further into a starker **noir** palette — true black canvas, crisp white ink, single emerald accent — inspired by dreamworkhq.com) — Schibsted Grotesk display over Instrument Sans, pill buttons/chips, rounded elevated cards — layered over shadcn/ui. It is a **scoped sub-theme** (not a global override) defined in `client/src/index.css` under the `.editorial` class (class + token names kept from the broadsheet era). The app is locked to dark mode (`<html class="dark">` in `index.html`, no user-facing toggle) — the `.dark .editorial` variant tokens are the only ones active; the light `.editorial` tokens are unused but left in place.

- **Tokens** (`--ed-*` CSS vars): `--ed-paper` (`#000`), `--ed-panel` (`#0a0a0a`), `--ed-ink` (`#fff`), `--ed-ink-soft`/`--ed-ink-faint` (neutral grays, no green cast), `--ed-rule`/`--ed-rule-strong` (white at low opacity), `--ed-accent` (emerald, `#2be08f`), `--ed-accent-deep`, `--ed-yes` (success green), `--ed-no` (signal red), `--ed-gold` (amber — kept as its own hue, distinct from `--ed-accent`, since it's semantically load-bearing for warning/MAYBE states, not decorative). Semantic mapping: success→`--ed-yes`, error/destructive→`--ed-no`, warning→`--ed-gold`, accent/primary→`--ed-accent`. The homepage's ambient mesh (`.home-atmosphere`) is the one place gold was dropped in favor of a single-hue `--ed-accent` glow, since it's purely decorative there and has no warning semantics to preserve.
- **Usage**: inside an editorial page, style with these tokens via Tailwind arbitrary values — `text-[var(--ed-ink)]`, `border-[var(--ed-rule)]`, `bg-[var(--ed-panel)]/40`, and `color-mix(in oklab, var(--ed-yes) 10%, transparent)` for tints — **not** the neutral shadcn tokens (`text-foreground`, `bg-card`, `text-muted-foreground`, …).
- **Helpers** (in `index.css`): `.editorial-grain` (emerald glow + faint noise atmosphere), `.ed-display` (Schibsted Grotesk, loaded in `index.html`), `.ed-rise` (staggered entry), `.ed-fill` (ruled-meter fill via inline `--p`). A **modern-skin layer** in `index.css` auto-rounds and elevates any element whose class contains `bg-[var(--ed-panel)` / `border-dashed`, rounds all form fields, and renders legacy `border-double` rules solid — new panels get the treatment for free by using the token classes.
- **Page pattern**: wrap in `<div className="editorial editorial-grain min-h-screen"><div className="relative z-[1] max-w-… mx-auto …">…</div></div>`; lead with a masthead (dateline rule + `ed-display` title with an italic emerald accent word + heavy rule) and italic/numbered `ed-display` section heads over heavy rules. Buttons and chips are pills (`rounded-full`); never reintroduce `rounded-none`.
- **Scope caveat**: `var(--ed-*)` only resolves **inside** the `.editorial` subtree. The global nav (`App.tsx`) stays neutral by design. **Do not** put `--ed-*` styling on anything rendered in a React **portal** (shadcn `Dialog`/`Select` content mounts at `document.body`, outside `.editorial`) or on a component shared with a non-editorial host.
- **Covered pages** (all editorial): Home (`LandingPage`), Search Matches (`SearchPage`), Tracker (Dashboard/Applications/Statistics/Add), Application detail, Score a Job, Interview Prep, Practice Interview, Interview Insights, Profile (`SettingsPage`/`/settings` — nav label reads "Profile"). Shared primitives: a local editorial `Button`, `SectionHeader`, and status **pills** (rounded-full, uppercase, tinted). (The Discovery page and its Run detail sub-page were removed from the client — criteria/runs are managed directly against the scraper API now.)
- **Status colors are centralized**: application statuses → `STATUS_TONE` in `components/Status.tsx` (also drives the Statistics breakdown bars) — extend it rather than re-coloring badges inline.
- **Reference**: `design-prototypes/editorial-broadsheet.html` is a self-contained mockup of the *original broadsheet* look — layout structure still matches, but colors/type/shape predate the Forest Ledger refresh.

## RTL / bidi content

The frontend is an English LTR SPA, but content can be mixed Hebrew RTL (AI summaries, prompts, interview text) — render those nodes with `dir="rtl"`/`dir="auto"`.
